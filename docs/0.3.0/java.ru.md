Версия библиотеки и версия Java — разные вещи. Артефакты 0.3.0 имеют базу Java 17. Запуск на более новой JVM сам по себе не означает, что библиотека использует каждый новый API или даёт измеренный прирост производительности.

## Java 17

Минимальная версия ядра. Компиляция с --release 17, class-file 61.0, без preview. Все основные возможности из руководства доступны на этой версии.

```sh
./gradlew build -PtestJavaVersion=17
```

Для build нужен отдельный тестовый PostgreSQL; параметры запуска указаны в README. Для установки без запуска тестов: ./gradlew publishToMavenLocal.

## Java 21

Новые API Java 21 в основной артефакт не добавлены: он продолжает использовать Java 17 и проверен на JVM 21. Переход на Java 21 не меняет публичный API или контракт библиотеки.

```sh
./gradlew build -PtestJavaVersion=21
```

## Java 25

Поддерживается запуск на JVM 25. ScopedValue и другие API Java 25 не включены в библиотеку: для её текущих задач отдельный адаптер не нужен. Минимум остаётся Java 17.

```sh
./gradlew build -PtestJavaVersion=25
```

## Java 27

Java 27 проверена как дополнительная non-LTS среда. Специальных API Java 27 в артефакте нет. Изменения GC, TLS и заголовков объектов относятся к JVM; библиотека не объявляет их собственными возможностями и не обещает непроверенный прирост скорости.

```sh
./gradlew build -PtestJavaVersion=27
```

## Что изменилось между версиями библиотеки

| Версия | Изменение требований и возможностей Java |
| --- | --- |
| 0.1.0 | База Java 17. |
| 0.2.0 | Историческая версия с обязательной Java 27; текущей рекомендацией не является. |
| 0.3.0 | Минимум снова Java 17; проверены JVM 17/21/25/27. Более новые API не повышают требования артефакта. |
